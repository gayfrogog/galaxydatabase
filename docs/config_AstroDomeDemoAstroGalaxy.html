Config: AstroDomeDemoAstroGalaxy

The small Comet Observatory model utilised in the galaxy selector. Acts as a variant of SimpleMapObj with an additional feature for its use in the galaxy selector. It has a three frame BRK file that brightens and darkens the observatory depending on which Grand Stars have been collected. If Grand Star 5 has been collected, freezes on frame 2. If Grand Star 3 has been collected, freezes on frame 1. Otherwise, freezes on frame 0.
