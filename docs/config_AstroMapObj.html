Config: AstroMapObj

An object class designed specifically for the Comet Observatory and its multiple stages of activation. Otherwise inherits most arguments from SimpleMapObjFarMax. Object will "activate" or start active (having already played its activation animations) if certain conditions are met.

Collected Grand Star: Defines what Grand Star is required for the object to activate.

*Additionally enables the kitchen smoke effect when set to 3.

  • 5: Bedroom
  • 6: Engine
