Config: AstroDomeSky

The skybox utilised in all 6 AstroDome layers. Has an obj_arg that changes the model used by the object. Plays a BTK animation for the model itself and has BTK files to show and hide the model when appropriate.

Arguments

NameTypeGamesRequired?DescriptionValues
Obj_arg0Integern/aFalse

Sky Model: Selects one of six available models for the object to use.

  • 1: Terrace
  • 2: Fountain
  • 3: Kitchen
  • 4: Bedroom
  • 5: Engine
  • 6: Garden
